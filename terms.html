이용약관

시행일: 2026년 9월 23일

이 약관은 Mollu(이하 “앱”)의 이용 조건을 정합니다. 앱을 설치하거나 사용하면 이 약관과 Apple 표준 사용권 계약(EULA)에 동의한 것으로 봅니다.

1. 서비스

앱은 스크린샷과 사진 속 글자를 인식하고 번역해, 원래 글자 자리에 번역을 표시합니다. 기능은 예고 없이 바뀌거나 중단될 수 있습니다.

2. 번역 결과

번역은 기계 번역이며 틀리거나 빠진 내용이 있을 수 있습니다. 의료, 법률, 금융, 안전 등 중요한 판단에는 번역 결과만으로 결정하지 말고 원문이나 전문가의 확인을 거치세요.

3. 사용자 콘텐츠

  • 번역하는 스크린샷과 사진에 대한 권리와 책임은 사용자에게 있습니다.
  • 타인의 저작물이나 개인정보가 담긴 화면을 번역·저장·공유할 때는 관련 법령과 권리자의 권리를 지켜 주세요.
  • 앱을 불법적인 목적이나 타인의 권리를 침해하는 데 사용해서는 안 됩니다.

4. 외부 번역 서비스

LLM 번역(Claude, ChatGPT, Gemini)은 사용자가 직접 발급한 API 키로 해당 제공자의 서비스를 이용하는 선택 기능입니다. 이 기능을 쓰면 각 제공자의 약관과 정책이 적용되며, API 사용 요금은 사용자의 계정에 청구됩니다. 개발자는 외부 서비스의 가용성, 요금, 처리 결과에 책임지지 않습니다.

5. 개인정보

개인정보 처리는 개인정보 처리방침을 따릅니다.

6. 책임의 제한

앱은 “있는 그대로” 제공됩니다. 관련 법령이 허용하는 범위에서, 개발자는 앱 사용이나 번역 결과로 생긴 손해에 대해 고의 또는 중대한 과실이 없는 한 책임지지 않습니다.

7. 약관 변경

약관이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 바뀐 약관 시행 후에도 앱을 계속 쓰면 바뀐 약관에 동의한 것으로 봅니다.

8. 준거법

이 약관은 대한민국 법률에 따릅니다.
